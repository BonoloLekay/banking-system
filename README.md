# Banking System

A portfolio banking simulation developed using Python and SQL.
This project demonstrates software development, database design, business analysis, transaction processing, authentication, testing and reporting.

## Planned Features

- Customer Management
- Bank Account management
- Deposits
- Withdrawals
- Account-to-account transfers
  -Transaction History
- Balance inquiries
- Authentiication
- Role-Based access control
- Admin dashboard
- Customer dashboard
- Reporting and analytics
